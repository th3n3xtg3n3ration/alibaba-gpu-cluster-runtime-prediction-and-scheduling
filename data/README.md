# Alibaba GPU Data Directory

This directory is intended to store the Alibaba PAI GPU workload traces.

## Dataset Source
The data used in this thesis is derived from the **Alibaba PAI GPU Cluster Trace (2022)**.
- **Paper:** "MLaaS in the Wild: Workload Analysis and Scheduling in Large-Scale Heterogeneous GPU Clusters" (NSDI '22).
- **Official Repository:** [Alibaba PAI GPU Trace](https://github.com/alibaba/pai-gpu-trace)

## Structure
- `alibaba_cluster_trace/`: Contains the original cluster trace (`pai_job_no_estimate_100K.csv`).
- `processed/`: Contains the preprocessed utilization-aware dataset (`100k_job_with_utilization_full.csv`) generated by `notebooks/en/00_data_preparation.ipynb` (or `notebooks/tr/00_veri_hazirlama.ipynb`).

## Note on Samples
This repository ships with a **100k-row sample** for demonstration and full reproducibility of the research pipeline. To run experiments on the full trace, place the raw CSV files into `data/alibaba_cluster_trace/`.
